## The Execution Cycle

```
Build → Measure → Learn → Improve → Review → Repeat
```

Every AI milestone from M22-M26 must:

1. **Build** — Implement one capability, pass 24-gate checklist
2. **Measure** — Track KPIs daily (week 1), then weekly
3. **Learn** — 3+ data-informed insights before optimizing
4. **Improve** — One measurable improvement per cycle
5. **Review** — Sprint AI Report filed, continue/redesign/deprecate
6. **Repeat** — Begin next cycle
