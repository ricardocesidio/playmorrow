# SEC-012 — sharp/libvips CVE Remediation Certification

**Finding:** SEC-012 (transitive P1) — sharp@0.34.5 via next@16.2.12
**Sprint:** SEC-012 Dependency-Drift Release (Session 33 continued, 2026-08-11)
**Date:** 2026-08-11
**Status:** 🟢 **REMEDIATED — NO EXPLOITABLE DEPENDENCY VULN REMAINS**

---

## 1. Executive Summary

The SEC-012 deep audit (2026-08-11, `SECURITY_TRANSITIVE_DEPENDENCY_AUDIT_V2.md`)
identified one partially-reachable P1 finding: **sharp@0.34.5** inherited libvips
vulnerabilities (CVE-2026-35591 TIFF, CVE-2026-33327 VIPS, CVE-2026-35590 EXIF)
reachable via `/_next/image` with attacker-controllable remote URLs.

**Remediation:** upgraded `next` 16.2.12 → **16.3.0** + `@next/bundle-analyzer`
16.2.12 → 16.3.0 (web workspace), which vendors **patched sharp@0.35.3
(libvips 8.18.3)**. Zero application code changes. No M23 frozen components
touched. All quality gates pass.

**Result:** `pnpm audit --prod` dropped 23 → 20 findings (sharp no longer
flagged; postcss via next dropped 4 → 2 as side effect). The remaining 20
findings are all deep-audited build-time/DOM-only, NOT REACHABLE in
Playmorrow's runtime.
